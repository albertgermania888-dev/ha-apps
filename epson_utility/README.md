# Epson Smart Service для Home Assistant

Дополнение (Add-on) для Home Assistant, предназначенное для сетевой печати и локального обслуживания струйных принтеров Epson. Аддон базируется на сервере печати CUPS, консольной утилите escputil и использует Ghostscript/ImageMagick для генерации предпросмотра документов.

## ✨ Ключевые возможности

*   **Автопоиск (mDNS/Zeroconf):** Автоматическое обнаружение принтера в локальной сети и прозрачное обновление IP-адреса.
*   **Авто-проверка дюз:** Встроенный таймер автономно отсчитывает заданное количество дней с момента последней цветной печати и запускает сервисную печать, чтобы предотвратить засыхание печатающей головки.
*   **Уведомления:** Интеграция со службами уведомлений Home Assistant (например, Telegram) для отправки отчетов о результатах печати и обслуживания.
*   **Мониторинг состояния:** Сенсоры для отслеживания статуса устройства (готов, печатает, нет бумаги) и вывода показаний износа "памперса".
*   **Печать и предпросмотр:** Веб-интерфейс для загрузки и печати документов (PDF, JPG, PNG) с настройками цветности, формата, качества и визуальным предпросмотром.

## ⚙️ Конфигурация (Configuration)

Настройки указываются во вкладке **Configuration** аддона в Home Assistant.

| Параметр | Описание | По умолчанию |
| :--- | :--- | :--- |
| `printer_ip` | IP-адрес принтера. Оставьте `auto` для автоматического поиска, либо укажите статический IP (например, `192.168.1.108`). | `auto` |
| `auto_check_enabled` | Включить встроенный таймер для защиты от засыхания дюз. | `false` |
| `auto_check_days` | Количество дней простоя перед автоматической проверкой дюз. | `7` |
| `notify_service` | Точное имя службы уведомлений HA (например, `notify.telegram_bot_123`). Если пусто — уведомления отключены. | *(пусто)* |

## 🤖 Интеграция с автоматизациями (REST Commands)

Для управления принтером из скриптов, автоматизаций или с кнопок на дашборде Home Assistant, необходимо прописать `rest_command` в файле `configuration.yaml` (в папке `config` вашего HA).

### 1. Добавление команд в configuration.yaml
Добавьте этот блок кода и перезагрузите Home Assistant:

```yaml
rest_command:
  # Команда печати тестовой проверки дюз
  epson_nozzle_check:
    url: "[http://127.0.0.1:8099/api/nozzle_check](http://127.0.0.1:8099/api/nozzle_check)"
    method: POST

  # Команда запуска прочистки печатающей головки
  epson_clean_head:
    url: "[http://127.0.0.1:8099/api/clean_head](http://127.0.0.1:8099/api/clean_head)"
    method: POST

  # Команда печати локальных файлов (из папки /share)
  epson_print_file:
    url: "[http://127.0.0.1:8099/api/print_local_file](http://127.0.0.1:8099/api/print_local_file)"
    method: POST
    headers:
      Content-Type: application/json
    payload: >
      {
        "file": "{{ file }}",
        "copies": "{{ copies | default('1') }}",
        "color": "{{ color | default('color') }}",
        "media": "{{ media | default('A4') }}",
        "quality": "{{ quality | default('4') }}",
        "orientation": "{{ orientation | default('3') }}",
        "pages": "{{ pages | default('') }}"
      }
```

### 2. Примеры использования

Теперь вы можете вызывать эти сервисы как `rest_command.название`.

**Пример 1: Запуск прочистки дюз по беспроводной кнопке (Zigbee)**
```yaml
alias: "Epson: Прочистка головки с кнопки"
trigger:
  - platform: state
    entity_id: sensor.zigbee_button_action
    to: "double_click"
action:
  - service: rest_command.epson_clean_head
```

**Пример 2: Принудительная проверка дюз по расписанию**
*(Актуально, если вы не используете встроенный в аддон авто-таймер)*
```yaml
alias: "Epson: Проверка дюз по воскресеньям"
trigger:
  - platform: time
    at: "12:00:00"
condition:
  - condition: time
    weekday:
      - sun
action:
  - service: rest_command.epson_nozzle_check
```

**Пример 3: Автоматическая печать документа**
*(Печатает файл `/share/coloring.pdf` в черно-белом режиме)*
```yaml
alias: "Epson: Печать раскраски"
trigger:
  # Ваш триггер (например, время или приход домой)
action:
  - service: rest_command.epson_print_file
    data:
      file: "/share/coloring.pdf"
      copies: "1"
      color: "monochrome" # Черно-белая печать
      quality: "4"        # 3 (черновик), 4 (стандарт), 5 (высокое)
      media: "A4"         # Бумага (A4 или 4x6)
      orientation: "3"    # 3 (книжная), 4 (альбомная)
```

## 📊 Сенсоры состояния (Sensors)

Аддон использует внутреннее API Home Assistant для автоматического обновления системных сенсоров. Их не нужно прописывать вручную, они сами появятся в системе:

*   `sensor.epson_status` — Состояние лотка и сети (Готов, Печатает, Нет бумаги, Выключен).
*   `sensor.epson_print_result` — Результат последней отправленной команды.
*   `sensor.epson_maintenance` — Уровень износа впитывающей прокладки (памперса).

Используйте эти сенсоры на дашборде или в качестве триггеров для оповещений (например, отправка сообщения, если статус сменился на "Нет бумаги").

## 🛠 Устранение неполадок (FAQ)

**В: Статус висит на "Поиск..." или "Не найден".**
Убедитесь, что в конфигурации аддона `host_network` установлен в `true` (это необходимо для работы mDNS-поиска). Либо вручную укажите IP-адрес принтера в настройках аддона вместо `auto`.

**В: Долго загружается предпросмотр при смене ориентации на альбомную.**
Отрисовка и поворот изображения через ImageMagick требует ресурсов процессора. На слабых серверах (например, Raspberry Pi 3) это может занимать несколько секунд.

**В: Не приходят уведомления в Telegram.**
Убедитесь, что вы скопировали правильное имя службы. Перейдите в "Панель разработчика" -> "Службы", найдите свой сервис телеграма (он обычно выглядит как `notify.telegram_bot...`) и вставьте это значение в конфигурацию аддона.
